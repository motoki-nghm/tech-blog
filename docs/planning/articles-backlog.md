# 記事バックログ

- 作成日: 2026-07-07
- 担当: 企画(クラピカ)
- 運用: アプリの素材が提供され次第、テンプレートに沿って具体化する。着手順は本ファイルの優先度に従う

## 運用ルール

- 1記事1メッセージ(伝えたいことを1つに絞る)。守れない場合は記事を分割する
- ステータス: `候補` → `構成済` → `執筆中` → `校正中` → `公開済`
- 素材が未提供の項目は書き始めない(推測で埋めない)

## シリーズテンプレート(1アプリ = 最低4記事)

アプリ素材が来たら、以下をコピーして具体化する。

### シリーズ: [アプリ名]

| # | 記事タイプ | 仮タイトル | 1メッセージ(この記事で伝えること) | ステータス |
|---|---|---|---|---|
| 1 | 事例サマリー | [課題]を[アプリ名]で解決した話 | どんな課題をどう解決し、何が変わったか | 候補 |
| 2 | 意思決定編 | [アプリ名]の技術選定で考えたこと | なぜその技術・AI活用範囲を選んだか | 候補 |
| 3 | AI協働実践編 | Claudeと作る[アプリ名] — 任せた部分と人が判断した部分 | AIとの協働の実際と、人の判断の価値 | 候補 |
| 4 | 技術深掘り編 | [実装テーマ]の実装ポイント | 技術担当者が検証できる実装の要点 | 候補 |

必要な素材(オーナー提供、箇条書きで可):
- アプリの背景(誰の・どんな課題か)/ 主要機能 / 成果や反応
- スクリーンショットまたはデモURL / リポジトリURL(公開可能なもののみ)
- 開発中に困った点・工夫した点のメモ
