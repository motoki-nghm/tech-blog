# デザインシステム

ポートフォリオ用テックブログのデザイントークンと決定記録。
実装は素の CSS カスタムプロパティ(CSS変数)で行う。SPA的な複雑さがなく、単カラム・少数コンポーネントの規模のため、Tailwind等のユーティリティフレームワークは導入しない(依存とビルドコストを増やさないポリシー準拠)。

トークンの実体は `src/styles/global.css` の `:root` に定義する。本ドキュメントは意図と数値の一次資料。

## 方向性

- 目的: フリーランスの営業先(発注者が主・非エンジニア寄り)からの信頼獲得。「読みやすさ」と「センスが伝わる第一印象」の両立。
- トーン: やわらかい誠実さ(B案)を基調に、紺の理知(A案)を一滴。奇をてらわず、無記名でもない中庸。
- 基調色: **ブルーグレー(スチールブルー系)**。硬すぎず、逃げてもいない中間色。

## タイポグラフィ

- 欧文/UI: `system-ui` ベースの端正なスタック(Web フォント未導入=表示が速い/依存を増やさない)。
- 和文: `"Noto Sans JP"` を優先し、無ければ游ゴシック系・ヒラギノにフォールバック。
- 将来ディスプレイ書体(見出し専用 Inter 等)を足す余地はあるが、初期は速度優先で見送り(実装拡張はキルア領分)。

### スケール(モジュラー、行間)

| 用途 | サイズ | 行間 |
|---|---|---|
| h1 | `clamp(1.9rem, 1.4rem + 2vw, 2.5rem)` | 1.25 |
| h2 | `1.5rem` | 1.3 |
| h3 | `1.2rem` | 1.35 |
| 本文 | `1rem`(≧768px で `1.0625rem`) | 1.75 |
| small/日付 | `0.85rem` | 1.5 |

- 見出しは `font-weight: 700`、字間 `letter-spacing: -0.01em` でわずかに締める。
- 本文は行間 1.75 を維持(読みやすさの土台)。

## スペーシング(4段+基準でリズムを作る)

| トークン | 値 |
|---|---|
| `--space-xs` | `0.5rem` |
| `--space-sm` | `1rem` |
| `--space-md` | `1.5rem` |
| `--space-lg` | `2.5rem` |
| `--space-xl` | `4rem` |

- 後方互換のため `--space`(= `1rem`)も維持。
- セクション間は `--space-lg`、ブロック内要素は `--space-sm`〜`--space-md` を基準に。

## 角丸・境界

| トークン | 値 | 用途 |
|---|---|---|
| `--radius-sm` | `6px` | タグ・ボタン内の小要素 |
| `--radius-md` | `10px` | カード・CTAパネル |
| `--radius-lg` | `16px` | ヒーロー等の大きな面 |

- 境界は 1px の静かなボーダーが基本。影(box-shadow)は多用せず、余白と罫で階層を作る。
- フォーカスリングは `--color-accent` のアウトラインで明示(アクセシビリティ)。

## レイアウト

- 本文カラム幅: `--content-width: 44rem`(継続)。
- ページ左右パディング: `--space-sm`。
- ヘッダーは上部固定せず、静かに罫で区切る(既存構造を踏襲)。
