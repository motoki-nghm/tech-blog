# tech-blog

ポートフォリオ用のテックブログです。

**Astro + MDX** によるGitベースのブログで、企画からデザイン・実装・執筆・レビュー・運用までを、HUNTER×HUNTERのキャラクターを模したAIエージェントチーム(Claude Code サブエージェント)と会話しながら進める構成になっています。

## 技術スタック

| 項目 | 採用 |
|---|---|
| フレームワーク | Astro |
| 記事フォーマット | MDX(コンテンツコレクション) |
| 言語 | TypeScript |
| コンテンツ管理 | Gitベース(外部CMSなし) |
| ホスティング(予定) | Cloudflare Pages / Vercel |

外部ヘッドレスCMSではなくGitベースを選んだのは、記事も設定もすべてリポジトリで完結し、AIエージェントと会話しながらそのまま執筆・レビューできるためです。

## エージェントチーム

`.claude/agents/` に定義。Claude Code 上で「キルアに◯◯を実装してもらって」「ゴンと記事を書きたい」のように呼び出せます。

| キャラ | 担当 | ひとこと |
|---|---|---|
| クラピカ | 企画・戦略 | 「結論から言おう。この企画には3つの選択肢がある」 |
| ヒソカ | デザイン | 「このタイポグラフィ、ゾクゾクするねぇ…♠」 |
| キルア | 実装 | 「ま、任せとけって。ビルドも通ってる」 |
| ゴン | 記事執筆 | 「この記事、誰に読んでほしい?」 |
| ビスケ | レビュー・品質 | 「甘ったれてんじゃないわよ!!」 |
| レオリオ | SEO・運用 | 「SEOってのは読者への案内板だ」 |

各エージェントは「ヒアリング → 提案 → 合意 → 実行」の対話サイクルで進めるよう設計されています。

## 使い方の例

```text
# 企画から始める
クラピカと相談して、ブログのコンセプトを固めたい

# 実装を進める
キルアにAstroの初期セットアップをお願い

# 記事を書く
ゴンと一緒に「◯◯でハマった話」の記事を書きたい

# 公開前チェック
ビスケに記事とコードをレビューしてもらって
```

## ディレクトリ構成(予定)

```text
.claude/agents/   エージェント定義
docs/planning/    企画書・記事バックログ(クラピカ)
docs/design/      デザインシステム(ヒソカ)
src/content/blog/ 記事本体(MDX)
```
